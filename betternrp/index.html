WHAT IT IS P.01

BetterRNP是一款面向课堂、会议和活动现场的 Windows 随机抽取工具。 它把随机点名、随机数字和随机座位集中在一个轻量桌面程序里： 不用准备表格公式，也不用临时写脚本，选好方案和模式即可开始滚动抽取。

程序支持常驻系统托盘、置顶悬浮球快速抽取、加密本地存储、可配置的照片背景， 以及 .rnpp 插件扩展。v2.0.0 起从 Java Swing 完整重写为 .NET 8 / C# / WPF，界面保持接近 Windows 原生对话框的观感； 旧版 Java 保存的加密名单、数字与座位数据可以继续读取。

WORKFLOW 06 STEPS
步骤说明
选择方案从顶部选择预设方案，可分别为不同班级 / 活动建立
切换模式名字列表、数字或座位模式，共用同一套方案与交互
开始抽取点击「开始抽取」，结果按 50ms 间隔滚动
停止定格再次点击「停止」保留最终结果，并写入操作日志
配置数据进入「配置名单」或对应模式窗口，显式保存修改
现场辅助在设置中启用托盘、悬浮球、背景主题与自动检查更新

抽取结果会写入 log/，并在 data/ 与备份目录保留多份副本

07 MODULES
三种抽取模式MODULE 01

名字列表、随机数字、随机座位共用同一套方案与交互，覆盖点名、抽号与排座。

  • 名字列表
  • 数字
  • 座位 30×30
滚停式抽取MODULE 02

结果快速轮换，点击停止后定格，比直接弹出结果更有现场氛围；每次抽取自动记录。

  • 50ms 轮换
  • 大字号投影
  • 操作日志
托盘与悬浮球MODULE 03

主窗口可隐藏到托盘，原生 Win32 右键菜单；悬浮球置顶、可拖动、双击即抽取。
